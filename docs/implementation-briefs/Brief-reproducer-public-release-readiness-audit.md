## Purpose

Audit:

```text

```

```text

```

Commit message:

```text

```

This is an **audit-only** exercise.

Do not perform broad remediation during the audit.

# 12. Critical packaging/data-location audit

The default CLI resolves canonical input files from the project/package data location.

Verify how this behaves under:

```text
editable install
ordinary non-editable install
wheel install
source checkout without installation
console-script invocation outside repo root
```

The question is not:

> Can we make every packaging mode work now?

The question is:

> Which modes actually work today, and does the documentation accurately state the supported mode?

If ordinary wheel/non-editable installation omits the canonical `data/` files or resolves them incorrectly:

- classify appropriately;
- do not automatically turn this audit into a packaging rewrite;
- recommend either:
  - package the data properly, or
  - explicitly document editable/source-checkout installation as the supported v1.0 mode.

A broken documented install/run path is a **BLOCKER**.

An undocumented unsupported packaging mode is not necessarily a blocker.

# Acceptance criteria

The audit is complete when:

1. exact commit `13594c4` has been audited;
2. current tree and reachable history have been assessed;
3. secrets/privacy and proprietary/debug artifacts have been scanned;
4. canonical data publication and provenance have been assessed;
5. xEdit scripts have been reviewed for public release;
6. README/docs are checked against actual 10E behavior;
7. fresh-clone install and CLI use have been tested;
8. package/data-location behavior has been characterized;
9. runtime validation/oracle boundaries have been verified;
10. full tests and canonical validation have been run;
11. product output contract has been reverified;
12. license status has been reported;
13. public-reader usability has been assessed;
14. a durable audit document exists;
15. every finding has severity and remediation;
16. the audit gives a clear READY / READY AFTER MINOR FIXES / NOT READY verdict;
17. no repository visibility, tag, release, package publication, history rewrite, commit, or push occurred.
