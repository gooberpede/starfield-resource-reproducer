# Audit archive

This directory contains the current audit index for 
`starfield-resource-reproducer`.

Completed historical audits are preserved in:

```text
audits.zip
```

Loose Markdown files in this directory should represent current or active 
audit work only.

The archived audit documents preserve the repository state, findings, 
remediation status, and release-readiness evidence as they existed at the 
time. They may therefore contain conclusions or references that have since 
been superseded by later remediation or repository changes.

For the current project state, use the root `README.md`, current 
documentation, source, tests, and Git history rather than treating an archived 
audit as current authority.

The v1.0 public-release audit cycle is complete and archived here for 
provenance.
